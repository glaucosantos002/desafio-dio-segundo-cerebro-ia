# 🧠 Segundo Cérebro com IA — Desafio DIO

## 📌 Sobre o projeto

Este projeto faz parte do desafio **Acelere sua Aprendizagem com IA: Explore o Poder do NotebookLM**, da Digital Innovation One (DIO).

O objetivo é construir um ambiente de aprendizagem com Inteligência Artificial, utilizando fontes confiáveis para estudar os fundamentos de Inteligência Artificial e Machine Learning.

## 🎯 Objetivos

- Criar um notebook de estudos com IA.
- Reunir materiais de aprendizagem confiáveis.
- Fazer perguntas e obter respostas fundamentadas nas fontes.
- Produzir materiais de revisão.
- Documentar o processo e os resultados no GitHub.

## 🛠️ Ferramentas utilizadas

- Google NotebookLM (Gemini Notebook)
- GitHub
- Materiais educacionais do Google e IBM

## 📚 Fontes de estudo

1. [Google — Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course?hl=pt-br)
2. [Google — Cursos fundamentais de Machine Learning](https://developers.google.com/machine-learning/foundational-courses)
3. [IBM — Artificial Intelligence](https://www.ibm.com/think/topics/artificial-intelligence)
4. [Google — Exercícios de Machine Learning](https://developers.google.com/machine-learning/crash-course/exercises?hl=pt-br)

As fontes efetivamente utilizadas e suas descrições estão documentadas em `fontes/referencias.md`.

## 🧩 Metodologia

O projeto foi organizado nas seguintes etapas:

1. Definição do tema de estudo.
2. Seleção de fontes confiáveis.
3. Criação do notebook.
4. Realização de perguntas fundamentadas nas fontes.
5. Geração de materiais complementares.
6. Organização e documentação dos resultados.

## 💬 Perguntas de pesquisa

As pesquisas abordam conceitos de Inteligência Artificial, Machine Learning, Deep Learning, tipos de aprendizado, redes neurais, treinamento de modelos, aplicações práticas e desafios éticos.

As perguntas, respostas e referências estão documentadas em `perguntas/perguntas-respostas.md`.

## 💡 Aprendizados e conclusões

Com esse projeto, consegui entender melhor como funciona a Inteligência Artificial e o Machine Learning, além de conhecer algumas aplicações dessas tecnologias.

O NotebookLM ajudou bastante a organizar os conteúdos e tirar dúvidas de forma mais rápida. Algumas partes foram mais difíceis de entender, mas os resumos e exemplos facilitaram o aprendizado.

## ✅ Resultado final

Criei um espaço de estudos no NotebookLM com fontes sobre IA e Machine Learning, além de perguntas, mapa mental, slides e resumo em áudio.

Foi uma experiência interessante para conhecer novas formas de estudar utilizando Inteligência Artificial.
